# 브릿지캠프 수강 신청 · 프론트엔드 (Level 2)

가상 IT·AI 교육 회사 **브릿지캠프**의 수강 신청 모바일 웹앱입니다. 과정을 검색·비교하고, 그 자리에서 기수를 골라 신청하고, 궁금한 점은 오른쪽 아래 상담 챗봇에게 바로 물어볼 수 있습니다.

> AX Campus 1기 · 빌더트랙 1차 과제 **Level 2** 제출. Level 3 기능(로그인·역할·GPT 챗봇)을 추가 기능으로 함께 구현했습니다. 모든 정보는 가상 데이터입니다.

- **배포 주소: https://bridgecamp-level2-frontend.vercel.app**
- 운영 화면: https://bridgecamp-level2-frontend.vercel.app/admin
- 백엔드 주소: https://bridgecamp-level2-backend.onrender.com ([/health](https://bridgecamp-level2-backend.onrender.com/health)) — 무료 서버라 첫 접속에 최대 1분 걸릴 수 있어요
- 기획서: [기획서.md](./기획서.md)
- 백엔드 저장소: [bridgecamp-level2-backend](https://github.com/kimdo127-cloud/bridgecamp-level2-backend)

## 확인용 계정

로그인 화면의 **확인용 계정** 버튼을 누르면 바로 로그인됩니다.

| 역할 | 아이디 | 비밀번호 | 할 수 있는 일 |
| --- | --- | --- | --- |
| 운영 매니저 (관리자) | `admin` | `admin1234` | 과정·기수 등록·수정, 운영 현황, 신청 전환 현황, 문의 내역·답변, 가상 데이터 다시 채우기 |
| 수강생 (일반) | `student` | `student1234` | 수강 신청, **내 신청만** 보기·취소, 운영팀 문의·답변 보기 |

## 이렇게 확인해 보세요
1. 목록에서 검색(예: `SQL`)하거나 분야·수업 방식 필터를 눌러 보세요.
2. **ChatGPT 업무 자동화 입문** → "수강 신청하기" → 로그인(수강생) → 6기는 이미 신청해 둔 상태라 **중복 신청 규칙**으로 거절돼요. 기수 일정에서 7기를 신청해 보세요.
3. **AI 서비스 기획 실무**는 1기가 신청 마감, 2기가 정원 마감 상태예요.
4. 오른쪽 위 "내 신청 ›"에서 개강 전 신청을 취소할 수 있어요.
5. 오른쪽 아래 로봇 버튼(챗봇)에 "이번 달에 개강하는 과정 있어요?", "환불 규정 알려 주세요"를 물어보세요.
6. 운영 매니저로 로그인 → **현황** 탭에서 숫자 3개와 신청 전환 현황, **가상 데이터 다시 채우기** 버튼을 확인하세요.
7. **문의 내역** 탭에서 로그인/비로그인 대화를 눌러 답변해 보세요. 비로그인 방문자는 같은 브라우저로 챗봇을 열면 답변과 빨간 점이 보여요.

관리자 계정으로 사용자 화면 주소에 들어오면 운영 화면으로 옮겨 갑니다 (모드 전환 버튼 없이 역할로 화면을 나눔).

## 화면

| 주소 | 화면 | 권한 |
| --- | --- | --- |
| `/` | 과정 목록 · 검색 · 필터 | 누구나 |
| `/courses/:id` | 과정 상세 · 기수별 남은 자리·신청 마감 · 수강 신청 | 누구나 (신청은 수강생) |
| `/login` | 로그인 · 확인용 계정 | 누구나 |
| `/me` | 내 신청 · 취소 · 운영팀 답변 | 수강생 |
| `/admin` | 과정 관리 | 관리자 |
| `/admin/stats` | 운영 현황 · 신청 전환 현황 · 가상 데이터 리셋 | 관리자 |
| `/admin/inquiries` | 문의 내역 (로그인 / 비로그인 탭) | 관리자 |
| `/admin/inquiries/:key` | 한 사람의 대화 · 운영팀 답변 보내기 | 관리자 |
| 오른쪽 아래 로봇 버튼 | 상담 챗봇 (GPT) · 운영팀 답변 · 저장 안내 (상세 화면에서는 숨김) | 누구나 (문의 남기기는 수강생) |

화면에서 숨기는 것과 별개로, 권한과 신청 규칙은 **백엔드가 매 요청마다 확인**합니다.

## 설정값

| 이름 | 뜻 |
| --- | --- |
| `NEXT_PUBLIC_API_URL` | 백엔드 주소. 로컬은 `http://localhost:4200`, Vercel은 Render 백엔드 주소 |

GPT 키는 프론트엔드에 넣지 않습니다. 챗봇은 백엔드의 `/chat`을 거쳐 GPT를 부릅니다.

## 로컬에서 실행

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL 채우기
npm run dev -- -p 3200       # http://localhost:3200
```

## 기술
Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · Vercel
